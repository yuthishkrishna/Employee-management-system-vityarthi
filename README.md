# Employee Management System

## 1. Project Title

**Employee Management System**

---

## 2. Overview of the Project

The Employee Management System is a Python-based console application designed to manage employee information efficiently.

The system allows users to add, view, update, delete, search, sort, and analyze employee records. Employee information is maintained in memory using a Python dictionary and is permanently stored in a CSV file named `Employee_Records.csv`.

The project uses the Pandas library for structured data processing and CSV file handling. When the application starts, previously saved employee records are loaded from the CSV file. Any changes made during execution are saved back to the CSV file.

The system provides a simple menu-driven interface so that users can perform different employee management operations without directly modifying the CSV file.

---

## 3. Features

### 3.1 Add Employee

Users can add a new employee by entering:

- Employee name
- Age
- Department
- Salary
- Date of joining
- Gender

A unique employee ID is automatically generated by the system.

---

### 3.2 Display Employee Details

The system can display the available employee records in a tabular format.

Employee information is converted into a Pandas DataFrame for easier viewing and processing.

---

### 3.3 Update Employee Details

The system allows users to update employee information such as:

- Age
- Department
- Salary
- Date of Joining

The existing employee ID and gender are preserved during the update.

---

### 3.4 Delete Employee

Users can search for an employee by name and delete the corresponding employee record.

The updated records are then saved to the CSV file.

---

### 3.5 Search Employee Details

The system provides two search options:

1. Search by employee name
2. Search by department

This allows users to retrieve individual employee information or view employees belonging to a particular department.

---

### 3.6 Sort Employee Records

Employee records can be sorted according to:

- Age
- Salary
- Department
- Date of Joining

---

### 3.7 Minimum/Maximum Analysis

The system can identify employees based on:

- Minimum age
- Maximum age
- Minimum salary
- Maximum salary

This provides a simple way to analyze employee data.

---

### 3.8 Clear All Employee Records

The system provides an option to remove all employee records from the application and save the empty dataset to the CSV file.

---

### 3.9 Persistent Data Storage

Employee records are stored in:

`Employee_Records.csv`

The application loads existing records when it starts and saves changes whenever employee data is modified.
